# Privacy and data map

Status: planning proposal, no real private research data collected and no system implemented. Owner: privacy lead/counsel before collection; [compliance](india-compliance-register.md).

| Data | Purpose / proposed lawful basis | Minimum access / sharing | Retention/deletion and unknown |
|---|---|---|---|
| Anonymous interview themes | Voluntary informed research consent | Research lead; public aggregate only | Proposed90 days raw notes, then delete; route and counsel approval before recruitment |
| Recruitment contacts / consent | Scheduling and withdrawal, separately consented | Private coordinator only; never Git | Separate key, shortest window, no marketing reuse; specific retention unresolved |
| Customer contact/account | Authentication and job communication | Customer/self; scoped backend, assigned merchant minimum | Recycled/shared number/recovery and deletion exceptions unresolved |
| Precise address/location | Eligibility and fulfillment | Explicit purpose; only assigned authorized party | Manual address option; restrict live tracking; duration not approved |
| Photos | Explain fault/verification only if necessary | Private storage, case-scoped access | Validate/scan, expire access, remove metadata; deletion/hold rule open |
| Merchant competence/evidence | Lawful verification | Assigned verifier, appeal scope | Do not collect Aadhaar/rawIDs by default; counsel establishes alternatives and lawful retention |
| Booking/dispute/accounting | Fulfillment and lawful records | Parties and assigned staff with masking | Separate eraseable data from mandated accounting/hold; exact schedules CA/counsel |
| Messaging/push identifiers | Consented notification and delivery correlation | Approved vendor with minimal payload | Token/consent revoke, no cross-customer forwarding; DPA/region unknown |
| Security/audit logs | Fraud/incident investigation | Narrow security scope | Redaction, clock sync, CERT-In/legal schedule reconciliation; no unnecessary message/body logging |

Proposed safeguards: purpose-specific notice in understood language; separate research and WhatsApp opt-in; deny unexpected/background data collection; list subprocessors/regions; actor/tenant authorization; retention schedule; export/correction/deletion request verification; legal-hold appeal; incident notification decision procedure. No security score assigned.

Public Git is not a research data store. A broad zone and rare quote can reidentify a person in a small town; suppress unique combinations, paraphrase by default, review aggregates. Owner must approve private storage/access and real withdrawal contact before recruitment. Consent template is not execution evidence. Deletion must cascade providers/storage/backups under documented exceptions rather than erase audit/accounting blindly.
