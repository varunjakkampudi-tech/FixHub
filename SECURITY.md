# Security policy

This repository currently contains planning documentation only. It is not an implemented service and has no application security certification or production security posture.

## Reporting a vulnerability

Use the repository's GitHub **Security** tab and its private vulnerability reporting feature when available. Do not report potential vulnerabilities in public issues or commit sensitive proof-of-concept data publicly. If private reporting is unavailable, contact the repository owner through an independently verified private channel; this file intentionally does not publish an unverified email address.

Please include the affected path or feature, impact, reproduction steps, and a safe way to coordinate remediation. Do not access, modify, or disclose other users' data.

## Scope and response

Only this repository is in scope. No service, deployment, response-time guarantee, or bounty program is represented here. Reports will be reviewed by the repository owner; application-security claims require implementation and test evidence and must not be inferred from this policy.
